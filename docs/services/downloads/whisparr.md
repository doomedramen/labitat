# Whisparr

Supports Whisparr V3 (default) and V2. Choose your application version when configuring the widget; both versions use the `/api/v3` API prefix.

## Configuration

Enter your instance URL and API key from **Settings → General → API Key**. Include any configured URL base in the URL. Select **V2** for studio-based instances.

## Widget displays

- Queued downloads
- Missing items
- Items below the desired quality cutoff (Wanted)
- Scenes / movies for V3, or series for V2
- Optional active downloads with progress, size, activity, and estimated time remaining

Enable both **Show active downloads** and **Show download queue** to display download details.
