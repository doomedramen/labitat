# Glances

Cross-platform system monitoring.

## Configuration

| Field    | Type     | Required | Description      |
| -------- | -------- | -------- | ---------------- |
| URL      | URL      | Yes      | Glances API URL  |
| Username | Text     | No       | Glances username |
| Password | Password | No       | Glances password |

## Widget Displays

- CPU usage
- Memory usage
- Swap usage
- Load per CPU core

Uptime is available in Unused. Choose metrics in the item editor; the default shows four.
